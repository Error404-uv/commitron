# Contributing

1. Open an issue describing the bug or proposed change.
2. Create a focused branch and keep changes small.
3. Install development dependencies with `python -m pip install -e ".[test]"`.
4. Run `pytest` and `ruff check src tests` before opening a pull request.
5. Never include API keys, credentials, private diffs, or personal data in tests or issue reports.

Please include the operating system, Python version, Git version, reproduction steps, and sanitized logs.
